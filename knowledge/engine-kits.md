# Engine genre kits (host-owned)

| Engine | Default layouts | LLM fills |
|--------|-----------------|-----------|
| **three** | FPS / arena / platformer via `templates/web-slice` + craft | novelty, AI, content |
| **pixel** | top-down + side via `templates/pixel-slice` | barks, extra systems |
| **vintage** | side / top dungeon via `templates/vintage-slice` | palette_id, room notes |

## Host buttons
- **Switch engine** — rebuild from stored prompt
- **One more room** — widen scroll / +coins (≤6 rooms vintage)
- **Vintage palette** — dmg / gbc-* only
- **Ship card** — engine · res · colors · P0 score
