# Fun-First Design (slim) — full craft lives in craft-taste.md + pair-partner.md + feel-tables.md

## Non-negotiables before writing systems
1. **Core verb** in one sentence: "You jump and bounce enemies" / "You aim under pressure"
2. **30-second fun**: can a stranger smile in 30s?
3. **Fail fast, retry faster**: death → restart < 2–3s
4. **One novelty**: one twist, not five genres mashed
5. **Readable goals**: player always knows next micro-goal

## Feel > features
- Prefer tuning CONFIG numbers over new menus
- Juice: hitstop, shake, particles, sound, flash — cheap dopamine
- Camera is part of feel (lag, punch, FOV kick)
- Input buffering / coyote / aim assist where genre needs it

## Vertical slice recipe
Playable character action → one challenge → one reward feedback → restart loop  
Only then: meta, progression, content volume.

## Playtest questions (Critic agent uses these)
1. Did I understand controls in <10s?
2. Was the first death fair?
3. Did something surprising feel good?
4. Would I do "one more run"?
5. What's the ugliest friction?

## Anti-patterns
- Feature laundry lists without a verb
- UI before movement feels good
- Copying AAA scope on solo/local AI
- Multiplayer before single-player fun
- On-chain complexity before core loop

## When stuck
Generate **3 variants** of the core loop (best-of-N), pick sharpest, kill the rest.
